# Languages

FaceRep speaks the same six languages as Elowa: English, Spanish, Portuguese (Brazil), German, French and Italian.

## How the language is chosen
1. iOS's per-app language (Settings app → FaceRep → Language), which iOS offers because the build lists the
   languages (`app.json` → `locales`). Settings → Language in the app opens that page; this is Apple's recommended way,
   so there is no second language switch inside the app. iOS restarts the app in the new language.
2. Otherwise the iPhone's languages in order (`expo-localization` `getLocales()`), matched to a supported code
   (`pt-PT` → `pt-BR`, `es-MX` → `es`; `matchLanguage()` in `src/i18n/index.ts`).
3. English.

The same language is used for the voice cues (with the device's regional voice when it has one: `en-GB`, `de-AT`…),
reminder notifications (rescheduled when the language changes), dates (`Intl`), and Coach replies (the Worker gets the
`locale` and the prompt says "reply in that language").

## Files
```
app/src/constants/i18n.ts          SUPPORTED_LANGUAGES, LANGUAGE_NAMES
app/src/i18n/index.ts              bundles every language statically (no network loading)
app/src/i18n/locales/<code>/*.json one file per namespace, same keys as en/
app/locales-native/<code>.json     app name and iOS permission texts (camera, microphone)
app/scripts/i18n-check.js          npm run i18n:check (also part of npm test)
docs/store-listing.md              App Store text per language
```

## Rules
- No hard-coded user-visible text, including accessibility labels: `t('namespace:key')`.
- Never glue translated pieces together; use `{{placeholders}}` and i18next plurals (`_one` / `_other`).
- Context keys for the picture choice (`_man` / `_woman`) and the massage program (`_massage`) exist in every language.
- `npm run i18n:check` fails on a missing or extra key, an empty text, or `{{placeholders}}` that differ from English.
- Keep health, safety, AI-consent and subscription text short and literal: never stronger than English (App Store 1.4.1,
  2.3.1, 3.1.2).
- Workout phase words show in capitals inside the timer ring: one short word.

## Adding a language
1. Add the code to `SUPPORTED_LANGUAGES` and its name to `LANGUAGE_NAMES`.
2. Copy `locales/en/` to `locales/<code>/`, translate, and add the imports in `src/i18n/index.ts`.
3. Add `locales-native/<code>.json` and register it in `app.json` → `locales` (needs a new build).
4. Add the speech fallback region in `services/workout/cues.ts` (`FALLBACK_REGION`).
5. `npm run i18n:check`, then the store text in `docs/store-listing.md`.

⚠️ The five translations were made with AI. Before launch in a country, have a native speaker check the safety screen,
AI consent, paywall, subscription text and the store listing.
